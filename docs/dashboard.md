# 面板功能

面板按集群、GPU 执行器、任务列表和任务详情组织实验信息。所有状态和指标来自队列记录、训练脚本或调度侧提供的监控快照；演示模式使用独立的虚构数据。

## 查看和筛选任务

顶部单独汇总运行中、排队中、已完成、失败和已取消任务。历史范围可选择全部、最近 24 小时、7 天或 30 天。统计遵循所选历史范围，不会因为搜索名称或切换列表状态而改变。

任务列表支持名称和 ID 搜索、状态筛选、运行优先或时间顺序排序，以及按服务端总数分页。筛选覆盖整个历史范围。改变筛选条件时返回第一页；刷新保留当前选中的任务。

GPU 执行器区域可以折叠。每个执行器展示 Slurm 作业 ID 和它负责的全部活跃任务，点击任务链接即可查看详情。任务关联不受列表当前页影响。心跳时间表示队列最近报告时间，执行器区域不自行探测显卡进程。

运行中的任务超过 10 分钟没有报告进度时，列表会显示提醒，“查看”可只显示这些任务。这是一条显示提醒，不改变队列状态，也不会停止或取消训练。

## 任务详情

详情包含四个标签页：

- **概览**：训练阶段、脚本报告的 epoch 和进度、运行时长、预计剩余时间、GPU 指标和最近日志。
- **日志**：选择队列尝试日志或项目日志，开关自动跟随，复制当前文本，或下载完整日志。
- **配置**：查看并复制当前任务的命令和工作目录。提交环境和环境变量中的密钥不会在这里展示。
- **运行记录**：查看所有尝试、执行器、Slurm 作业 ID、开始/结束时间和退出状态。

epoch 总数来自脚本进度或已知命令参数。预计剩余时间只显示脚本明确报告的值，缺失时显示未报告；面板不把训练预算的结束时间推断成验证或最终评估的完成时间。

GPU 利用率和显存来自调度侧提供的 JSON 监控快照，并附带数据时间。没有该快照时显示暂无指标，不用零值代替，也不运行显卡探测命令。

“查看产物”只列出任务已知输出目录中的文件元数据和路径。它不会提供任意服务器路径浏览，也不会将文件内容直接显示在页面里。

## 刷新与操作

可以手动刷新或开启定时刷新。任务和日志请求发生竞争时，以当前选择的任务为准；读取失败会保留最后一次成功的数据，并提供重试提示。关闭日志跟随后，刷新尽量保留日志滚动位置。

演示模式可以确认取消虚构任务，方便体验完整交互。真实队列默认保持只读；启用取消功能时，操作人需要在确认框中输入操作令牌。令牌只用于当前请求，不写入 URL、浏览器持久存储或页面配置。服务端接受取消请求后，页面继续读取队列实际状态，不会直接将请求已接受显示为任务已结束。

日志下载、产物查看和取消按钮遵循服务端声明的可用能力；功能未启用时会显示原因。复制按钮仅复制页面中可见的配置或当前日志。

## 浏览器回归

`pnpm test:browser` 使用独立的内存演示队列，验证筛选、分页、执行器联动、详情标签、日志操作、错误恢复、延迟请求、文本渲染以及桌面和手机布局。支持的操作会在演示队列内完成，不读取或取消真实任务。

在需要通过 Slurm 运行测试的环境中，将命令提交给队列：

```bash
gpuq submit --name slurm-panel-browser --cwd /opt/slurm-panel -- pnpm test:browser
```

设置 `PANEL_SCREENSHOT_DIR` 可保存桌面和手机演示截图。截图仅使用虚构记录，适合附到 PR 或项目文档中。
